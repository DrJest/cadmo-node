Programma del corso Node.js & Express (80 ore)

Sviluppo backend con JavaScript: server, API REST, database, sicurezza, test e deploy.

Presentazione

Il corso accompagna i partecipanti dalla prima installazione di Node.js fino alla pubblicazione online di un'applicazione backend completa. Si parte dai fondamenti del runtime (event loop, programmazione asincrona, moduli), si passa al protocollo HTTP e al framework Express, per arrivare a database relazionali e NoSQL, autenticazione, sicurezza, test automatici e deploy.

L'approccio è fortemente pratico: ogni modulo alterna brevi momenti di teoria a simulazioni interattive e laboratori di codice, e si conclude con un project work di gruppo.

Obiettivi formativi

Al termine del corso il partecipante sarà in grado di:

  • $comprendere il modello di esecuzione di Node.js e scrivere codice asincrono corretto (callback, Promise, async/await);
  • $gestire progetti e dipendenze con npm e organizzare il codice in moduli;
  • $conoscere il protocollo HTTP e progettare API REST coerenti, validate e documentate;
  • $sviluppare applicazioni con Express usando routing, middleware e gestione centralizzata degli errori;
  • $persistere i dati su database relazionali (SQL, SQLite, Prisma) e documentali (MongoDB);
  • $implementare autenticazione e autorizzazione e applicare le principali misure di sicurezza;
  • $scrivere test automatici e pubblicare un'applicazione in produzione (Docker, cloud).

Prerequisiti

  • JavaScript di base: variabili, funzioni, array, oggetti, cicli e condizioni.
  • Uso del terminale e della riga di comando (vedi il corso Linux).
  • Nozioni minime di HTML.

Metodologia

  • Slide interattive per ogni lezione.
  • Simulazioni nel browser con un runtime Node.js simulato (terminale, npm, client HTTP).
  • Laboratori di codice con verifica automatica.
  • Missioni da svolgere sul proprio PC.
  • Quiz di fine modulo e project work finale.

Strumenti

  • Node.js LTS (24) e npm
  • Visual Studio Code, Git
  • Client HTTP: Bruno, Postman o Thunder Client
  • DevTools del browser
  • In seguito: SQLite, MongoDB, Docker
