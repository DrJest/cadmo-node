MAJOR.MINOR.PATCH — la MAJOR rompe la compatibilità.

"^5.1.0"  →  ≥ 5.1.0  e  < 6.0.0   (default)
"~5.1.0"  →  ≥ 5.1.0  e  < 5.2.0
"5.1.0"   →  esattamente 5.1.0

fs/promises + JSON

const fs = require('node:fs/promises');
const path = require('node:path');
const FILE = path.join(__dirname, 'dati.json');

async function main() {
  const dati = JSON.parse(await fs.readFile(FILE, 'utf8'));
  dati.push({ id: 3 });
  await fs.writeFile(FILE, JSON.stringify(dati, null, 2));
}

EventEmitter

const EventEmitter = require('node:events');

class Sensore extends EventEmitter {
  misura(t) { this.emit('dato', t); }   // sincrono!
}
const s = new Sensore();
s.on('dato', (t) => console.log(`${t} °C`));
s.on('error', (err) => console.error(err.message));

Missione A: Il primo progetto vero

Focus: npm init, dipendenze, script, .gitignore

  1. Crea la cartella corso-node/lezione2, entraci e inizializza il progetto con le risposte di default.
  2. Installa express come dipendenza e nodemon come devDependency. Apri package.json: dove sono finiti?
  3. Crea index.js che stampa Pronto! e aggiungi gli script start (node) e dev (nodemon).
  4. Lancia npm run dev, modifica il messaggio e salva: cosa succede nel terminale? Esci con Ctrl+C.
  5. Crea un .gitignore che escluda node_modules/ e .env.
  6. Cancella node_modules e ricrealo. Poi prova npm ci: che differenza noti?
mkdir -p corso-node/lezione2 && cd corso-node/lezione2
npm init -y
npm install express
npm install -D nodemon
echo "console.log('Pronto!');" > index.js
npm pkg set scripts.start="node index.js" scripts.dev="nodemon index.js"
npm run dev            # salva index.js → "[nodemon] restarting due to changes..."
printf "node_modules/\n.env\n" > .gitignore
rm -rf node_modules    # su Windows: Remove-Item -Recurse -Force node_modules
npm install            # ricrea node_modules da package.json (+ lock)
npm ci                 # cancella node_modules e installa ESATTAMENTE il lock

Missione B: Segreti nell'ambiente

Focus: process.env, --env-file, exit code

  1. Crea config.js che stampa Benvenuto <NOME>, server sulla porta <PORTA> leggendo le variabili NOME e PORTA (default: ospite e 3000).
  2. Lancialo senza variabili, poi impostandole solo per quel comando.
  3. Crea un file .env con le due variabili e lancia con node --env-file=.env config.js.
  4. Se PORTA non è un numero valido, stampa un errore su stderr ed esci con codice 2. Verifica il codice d'uscita con echo $? (PowerShell: $LASTEXITCODE).
// config.js
const nome = process.env.NOME ?? 'ospite';
const porta = Number(process.env.PORTA ?? 3000);

if (!Number.isInteger(porta) || porta < 1 || porta > 65535) {
  console.error(`PORTA non valida: ${process.env.PORTA}`);
  process.exit(2);
}

console.log(`Benvenuto ${nome}, server sulla porta ${porta}`);
node config.js                        # Benvenuto ospite, server sulla porta 3000
NOME=Anna PORTA=8080 node config.js   # macOS / Linux
# PowerShell: $env:NOME="Anna"; $env:PORTA="8080"; node config.js
printf "NOME=Luca\nPORTA=5000\n" > .env
node --env-file=.env config.js        # Benvenuto Luca, server sulla porta 5000
PORTA=ciao node config.js; echo $?    # PORTA non valida: ciao  →  2

Missione C: Detective di node_modules

Focus: albero delle dipendenze, lock, versioni

  1. Nel progetto della Missione A: quanti pacchetti ci sono in node_modules? Perché così tanti, se ne hai installati due?
  2. Mostra l'albero completo di chi dipende da chi, poi cerca chi usa il pacchetto debug.
  3. Controlla la versione di express in tre posti: package.json, package-lock.json, node_modules/express/package.json.
  4. Installa di proposito express@4: cosa cambia nel package.json? Cosa dice npm outdated? Poi torna a Express 5.
ls node_modules | wc -l          # decine di pacchetti: le dipendenze delle dipendenze!
npm ls --all                     # albero completo
npm ls debug                     # chi dipende da "debug"
grep '"express"' package.json
grep -A2 '"node_modules/express"' package-lock.json
grep '"version"' node_modules/express/package.json
npm install express@4            # package.json → "express": "^4.x.x"
npm outdated                     # Current 4.x, Latest 5.x (MAJOR diversa!)
npm install express@latest       # si torna alla 5

} else if (comando === 'remove') {
