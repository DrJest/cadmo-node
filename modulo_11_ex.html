Schema

new mongoose.Schema({
  titolo: { type: String, required: true, trim: true },
  anno: { type: Number, min: 1450, max: 2026 },
  isbn: { type: String, unique: true, sparse: true },
  generi: [String],
  autore: { type: Schema.Types.ObjectId, ref: 'Autore' },
  prestiti: [{ lettore: String, dal: { type: Date, default: Date.now } }],
}, { timestamps: true });

Aggiornamenti

await Libro.findByIdAndUpdate(id, { anno },
  { returnDocument: 'after', runValidators: true });
await Libro.updateOne(filtro, { $inc: { copie: 1 }, $push: { generi: 'x' } });
// $set $unset $inc $push $addToSet $pull · 'prestiti.$.al'
await Libro.findOneAndUpdate({ _id, disponibile: true },  // atomico
  { $set: { disponibile: false }, $push: { prestiti: { lettore } } });

2. Console mongosh, playground e "che cosa succede?"

La console mongosh

Il database biblioteca con 7 libri: generi è un array, i prestiti stanno dentro il libro. Scrivi uno o più comandi (uno per riga, come nella shell vera); i dati restano tra un'esecuzione e l'altra, Ripristina li rimette come all'inizio. Ctrl+Invio esegue.

🎯 Cinque sfide per la console (con le soluzioni)
  1. I titoli dei libri di Italo Calvino usciti dopo il 1960.
  2. Quanti libri hanno più di un genere? (suggerimento: $size non accetta $gt…)
  3. Aggiungi il genere classici a "Il barone rampante" senza creare doppioni, anche eseguendo il comando due volte.
  4. I libri con un prestito di Giulia ancora aperto (al mancante o null).
  5. Per ogni autore, quanti libri e l'anno del primo, dal più prolifico.
// 1
db.libri.find({ autore: 'Italo Calvino', anno: { $gt: 1960 } }, { titolo: 1, _id: 0 })
// 2 — "almeno 2 elementi" = esiste l'elemento con indice 1
db.libri.countDocuments({ 'generi.1': { $exists: true } })
// 3 — $addToSet aggiunge solo se manca ($push aggiungerebbe ogni volta)
db.libri.updateOne({ titolo: 'Il barone rampante' }, { $addToSet: { generi: 'classici' } })
// 4 — lettore e al nello STESSO elemento dell'array: $elemMatch ({ al: null } trova anche "al" mancante)
db.libri.find({ prestiti: { $elemMatch: { lettore: 'Giulia', al: null } } }, { titolo: 1 })
// 5
db.libri.aggregate([
  { $group: { _id: '$autore', libri: { $sum: 1 }, primo: { $min: '$anno' } } },
  { $sort: { libri: -1, _id: 1 } }
])

5. Missioni sul tuo PC

Missione A: La Biblioteca 8.0 su MongoDB Atlas

Focus: cluster gratuito, stringa di connessione in .env, Compass

  1. Su cloud.mongodb.com crea un cluster M0 (gratuito), un utente del database con password e, in Network Access, abilita il tuo indirizzo IP. Copia la stringa di connessione per i "Drivers".
  2. Crea corso-node/lezione11, installa express, morgan, zod e mongoose, ricopia i file della Biblioteca 8.0 (sezione 3) e metti la stringa in .env come MONGODB_URI (con /biblioteca prima del ?). Avvia con node --env-file=.env --watch server.js.
  3. Installa MongoDB Compass e collegati con la stessa stringa: trova il database biblioteca, le collezioni, gli indici (isbn_1, nome_1) e un libro con i suoi prestiti.
  4. Sbaglia apposta la password nella stringa e riavvia: che errore compare, e dopo quanto? E con l'IP non abilitato?

Missione B: Indici ed explain con mongosh

Focus: COLLSCAN vs IXSCAN, createIndex, indici composti, l'aggregation builder di Compass

  1. Apri mongosh (in Compass, in basso) sul database della missione A e crea 10000 libri finti con un ciclo for e insertMany (titolo, anno casuale tra 1900 e 2025, un genere a caso).
  2. Esegui db.libri.find({ anno: 1987 }).explain('executionStats'): guarda winningPlan.stage, totalDocsExamined e executionTimeMillis.
  3. Crea un indice su anno e ripeti. Poi prova { genere: 'giallo', anno: { $gte: 2000 } } con un indice composto { genere: 1, anno: 1 }: e con { anno: 1, genere: 1 }?
  4. In Compass, scheda Aggregations: ricostruisci con i blocchi la pipeline di /api/statistiche e esportala in JavaScript ("Export to language").
// 1. diecimila libri in una volta
const generi = ['romanzo', 'giallo', 'racconti', 'memorie', 'poesia'];
const finti = [];
for (let i = 0; i < 10000; i++) {
  finti.push({ titolo: `Libro ${i}`, anno: 1900 + Math.floor(Math.random() * 126), genere: generi[i % 5] });
}
db.libri.insertMany(finti)

// 2. senza indice: COLLSCAN, totalDocsExamined ≈ 10000 (li legge tutti)
db.libri.find({ anno: 1987 }).explain('executionStats').executionStats

// 3. con l'indice: IXSCAN, totalDocsExamined = quanti ne restituisce (≈ 80)
db.libri.createIndex({ anno: 1 })
db.libri.find({ anno: 1987 }).explain('executionStats').executionStats

// indice composto: prima il campo con l'uguaglianza, poi quello con l'intervallo
db.libri.createIndex({ genere: 1, anno: 1 })
db.libri.find({ genere: 'giallo', anno: { $gte: 2000 } }).explain('executionStats')
// con { anno: 1, genere: 1 } l'indice si usa lo stesso, ma deve scorrere tutti gli anni ≥ 2000
// (anche degli altri generi): totalKeysExamined più alto. Regola "ESR": Equality, Sort, Range.

// 4. dalla scheda Aggregations: $unwind → $group → $sort → $project, poi "Export to language" → Node
